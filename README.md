# HASINI GRANITE MEASUREMENT SHEET

## GitHub Pages files
Upload **all files and folders in this project** to the root of the repository `HASINI-GRANITE-MEASUREMENT-SHEET`, Upload every file directly into the repository root; this package uses no subfolders.

- `index.html` — app and PDF layout
- `manifest.json` — installable PWA name and icons
- `sw.js` — service worker cache, updated to v2
- `icon-192.png` and `icon-512.png` — app icons
- `icon-512-maskable.png` — maskable Android icon
- `hasini-granite-full-hd.png` — original HD icon
- `.nojekyll` — GitHub Pages helper

GitHub Pages URL:
https://saichandu1999.github.io/HASINI-GRANITE-MEASUREMENT-SHEET/

After uploading, wait for Pages to deploy, then open the URL and refresh. If an old version remains, close the app/site and reopen after a refresh. This ZIP prepares the files but does not upload them to GitHub automatically.
